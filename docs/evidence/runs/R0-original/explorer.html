Why the last seconds are hard

    Ideas to try

    • Tune the end-game model (done once: E4). It's XGBoost trained only on the last 3 minutes, blended in from 3:00 to 2:00. Try a longer window (ENDGAME_START in model/predict.py), other tree settings (ENDGAME_PARAMS in model/train.py), or giving it inputs only the end needs. docs/experiments/e4_endgame_settings.py is the sweep that picked the current settings.
    • Make close finishes count for more in training. Give late, close plays a bigger weight (scikit-learn's sample_weight, XGBoost's weight on the DMatrix). Watch the calibration chart: weighting can make the model overconfident early.
    • One row per possession, not per play. Substitutions and timeouts add rows where nothing changes. Dropping them makes each real moment count once. Built in pipeline/features.py.
    • Give the models what decides the end. Timeouts left and the foul bonus can be counted from the play-by-play; the NBA's own possession field is in the live feed (scripts/check_possession.py already reads it).
    • Check every change here. Run make train and then make explore, and compare this page before and after. Decide on the validation season (2024-25); docs/EXPERIMENTS.md has what's been tried.
